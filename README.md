# Ruang Warisan

An interactive museum guide prototype for an HCI design exercise. Explore a 3D replica, compare a historical reconstruction, plan a gallery route, take a virtual tour, and complete a discovery trail.

Open [the live prototype](https://ruang-warisan-xr-alpha.docileeasel.chatgpt.site/). To run it locally, serve the repository root with any static web server and open `index.html`.

The exhibits and routes are illustrative. Trail progress is saved in the visitor's browser. The optional camera view uses the camera on the visitor's device and does not upload video.
